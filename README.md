# obsidian-rpg-system
O Obsidian rpg System é um projeto em desenvolvimento cujo objetivo é criar uma plataforma online para criação, gerenciamento e evolução de fichas de RPG, com foco em arquitetura sólida, automação de regras e escalabilidade.

O sistema nasce a partir da modelagem de uma ficha complexa (inspirada em sistemas modernos de RPG), mas é projetado desde o início para suportar múltiplos sistemas, expansões futuras, campanhas, exportação em PDF e integração com back-end.

# 🏗️ Stack Tecnológica
## Front-end (fase atual)

HTML

CSS

JavaScript (organizado em módulos)

## Back-end (planejado)

Python

API própria

Camada de domínio espelhada

Persistência em banco de dados

Autenticação e controle de acesso

# 🎯 Objetivos do Projeto

Criar um núcleo robusto de personagem (estado único da verdade)

Implementar um motor de regras e cálculos derivados

Permitir criação, edição e persistência de fichas

Exportar fichas em PDF

Preparar o sistema para campanhas, automações e rolagens
