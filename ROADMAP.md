# 🏗️ FASE 1 — Fundação do Sistema (Base Técnica)

Objetivo: Criar um núcleo confiável, independente de interface.

Entregáveis

Estrutura definitiva do repositório

Organização das camadas (core, modules, services, ui)

Modelo de estado completo do personagem

Sistema central de atualização (engine)

Motor de recálculo de atributos derivados

Validações e consistência

Persistência local inicial

Casos de teste conceituais

Critério de conclusão

Personagem pode ser criado, alterado, recalculado e salvo

Nenhuma regra crítica depende da interface

Estado do personagem é sempre coerente

# ⚙️ FASE 2 — Sistema Funcional (Primeiro Produto)

Objetivo: Tornar o sistema utilizável.

Entregáveis

Interface mínima de criação de personagem

Visualização completa da ficha

Edição controlada dos campos

Salvamento e carregamento funcional

Organização modular das áreas (atributos, perícias, combate, inventário)

Sistema básico de histórico de alterações

Critério de conclusão

Usuário consegue criar e manter fichas reais

Sistema se comporta de forma previsível

Núcleo validado na prática

# 🧠 FASE 3 — Consolidação de Regras

Objetivo: Automatizar o máximo possível da ficha.

Entregáveis

Campos derivados automáticos

Dependências entre atributos

Sistema de modificadores

Estados do personagem (condições, efeitos, penalidades)

Sistema de recursos dinâmicos

Validações avançadas

Critério de conclusão

Alterar um valor impacta corretamente todo o personagem

Sistema impede estados inválidos

Redução máxima de cálculos manuais

# 📄 FASE 4 — Exportação e Apresentação

Objetivo: Transformar o sistema em ferramenta completa.

Entregáveis

Exportação de ficha em PDF

Templates visuais

Modo impressão

Organização visual final da ficha

Versão pública demonstrável

Critério de conclusão

Fichas exportáveis

Sistema apresentável para usuários finais

Material de portfólio sólido

# 🌐 FASE 5 — Back-end e Sistema Online

# 🧩 FASE 6 — Expansão de Plataforma

Objetivo: Evoluir de ficha para ecossistema.

Critério de conclusão

Base para novos módulos
